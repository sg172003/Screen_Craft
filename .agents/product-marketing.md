# ScreenCraft — Product Marketing Context

## Product
**ScreenCraft** is a free, privacy-first, 100% client-side web application that turns raw screenshots and screen recordings into polished, professional-grade visuals.

## URL
https://screen-craft.vercel.app/

## Type
SaaS-like web tool (no backend, no accounts). Single-page application.

## Target Audience
- Indie hackers and solo developers building products
- SaaS founders needing polished marketing assets
- Designers creating portfolio pieces
- Content creators preparing social media visuals
- Chrome extension developers creating Web Store listings

## Primary Keywords
- screenshot mockup generator
- screenshot editor online free
- browser frame screenshot tool
- screenshot beautifier
- screen recording mockup
- device frame generator
- free mockup tool no signup

## Key Differentiators
1. **100% Client-Side** — no uploads, no servers, no accounts
2. **Privacy-First** — media never leaves the browser
3. **Free Forever** — no freemium, no paywalls
4. **Video + Image** — handles both screenshots AND screen recordings
5. **High-DPI Export** — 1x/2x/3x Retina-quality PNG output
6. **Clipboard Paste** — Ctrl+V to import directly from system capture
7. **PWA / Offline** — works without internet after first visit

## Core Features
- Browser frame (macOS style), desktop frame, mobile phone frame
- Solid color, gradient, and blurred backgrounds
- Padding, corner radius, shadow controls
- Canvas size presets for Chrome Web Store, Twitter/X, Instagram, LinkedIn, Product Hunt, Dribbble
- PNG export at multiple scales + clipboard copy
- MP4/WebM video export with beautification
- Video playback controls (play, pause, scrub, mute, loop)
- Single-frame video capture (screenshot from recording)

## Competitors
- Screely, Shottr, CleanShot X, Pika.style, mockuphone.com, Promo.com screenshot tools

## Tech Stack
React 19, TypeScript, Vite, Tailwind CSS, HTML Canvas API, MediaRecorder API

Vercel (Hobby plan), custom domain not yet configured
