# Sources — methodology references

This folder archives **notes** about external sources that inform the toolkit's methodology. Each note follows the same format:

- **URL** to the original source (canonical)
- **Author / date / publication** for traceability
- **Triage** per `tasks/lessons.md` rule "Critical thinking on every source":
  - 🟢 **Universal** — applies to any real business
  - 🟡 **Context-specific** — only works in the original setting (don't blindly transpose)
  - 🟠 **Hard-mode-gated** — works broadly but needs preconditions
  - 🔴 **Over-claimed** — original measurement does not directly support the claim made
- **Key insights** integrated into the toolkit
- **What we explicitly did NOT integrate** (and why)

We don't archive full article text (copyright). We archive notes that make our methodology decisions traceable and auditable.

When a new source is integrated, add a note here, then reference it from the relevant doc in `docs/`.
