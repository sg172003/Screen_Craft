# Source #03 — WordLift / Volpini et al.: Enhanced Entity Pages improve RAG precision

- **URL paper:** https://arxiv.org/abs/2603.10700
- **URL repo:** https://github.com/wordlift/seo3-reasoning-web
- **Authors:** Volpini, A. et al. (WordLift)
- **Date:** 2026-03 (arXiv preprint)
- **Type:** Peer-reviewable empirical study (n=2 443 evaluations, 4 verticals, 7 conditions)

## Triage

🟢 **Universal — strongest empirical evidence we have on structured data + RAG**

- **JSON-LD in a hidden `<script>` adds only +0.17 pt** to RAG precision (negligible). Often truncated at indexation (Vertex AI ~20k char limit).
- **Enhanced Entity Pages** (visible JSON-LD in body + dereferenceable links + agent-instructions section + breadcrumbs) score **4.69/5 vs 3.62/5** for raw HTML — **+29.6% improvement**, effect size medium (d=0.60), p<10⁻²¹.
- New emerging pattern: a `<section class="agent-instructions">` block in HTML containing SYSTEM/INSTRUCTION/PRIORITY/FORMAT lines for LLM agents that parse the page.
- Agentic RAG **compensates** poor structure (+0.74 pt on raw HTML) but adds **almost nothing** on already-structured content (4.69 → 4.70). Implication: structure beats agent compute.
- Per-vertical gains are heterogeneous: e-commerce already saturated (+0.07), editorial / travel / legal explode (+1.50 to +2.73). The gain is proportional to what raw HTML doesn't already say.

🟡 **Context-specific** — none flagged; the study is a controlled benchmark, not a tactic that depends on a fictitious setting.

🟠 **Hard-mode-gated**

- Building a real Knowledge Graph with dereferenceable URIs requires non-trivial infrastructure. Many sites can adopt the **lighter version** (visible JSON-LD + breadcrumbs + agent-instructions block) without a full KG.

🔴 **Over-claimed considerations (limitations to keep in mind)**

- **Single retrieval system**: Vertex AI Vector Search 2.0 + gemini-embedding-001. Results are specific to this flat-text architecture. Other RAG stacks may behave differently.
- **Ground-truth circularity**: reference answers are derived from the same KG that enriches the pages. Conditions C3/C6/C6+ can score higher partly because evaluation rewards textual proximity to KG facts.
- **No ablation isolating agent-instructions**: we don't know what each component (visible JSON-LD vs navigable links vs NL summary vs agent-instructions block) contributes individually.
