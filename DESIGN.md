# Design System: Clean Studio

<!-- impeccable:design-tokens 1 -->

## World Thesis
Clean Studio is a modern, distraction-free visual design system built for ScreenCraft. It emphasizes clarity, honest product truth, and effortless ergonomics. Instead of generic AI-slop gradients or dark-only themes, it provides a seamless, beautiful experience across both **Light Mode** and **Dark Mode** with exceptional mobile responsiveness.

## Color System

### Light Theme
- **Page Background:** `#f8fafc` (Slate 50)
- **Card & Surface Background:** `#ffffff` (Pure White)
- **Subtle Surface Well:** `#f1f5f9` (Slate 100)
- **Primary Text:** `#0f172a` (Slate 900)
- **Secondary Text:** `#475569` (Slate 600)
- **Muted Text:** `#64748b` (Slate 500)
- **Borders & Dividers:** `#e2e8f0` (Slate 200)

### Dark Theme
- **Page Background:** `#0c0e14` (Deep Charcoal)
- **Card & Surface Background:** `#131620` (Dark Slate Panel)
- **Subtle Surface Well:** `#090b10` (Dark Canvas Well)
- **Primary Text:** `#f8fafc` (Slate 50)
- **Secondary Text:** `#94a3b8` (Slate 400)
- **Muted Text:** `#64748b` (Slate 500)
- **Borders & Dividers:** `#1e2430` (Slate 800)

### Brand Accent
- **Primary Indigo:** `#4f46e5` / `#6366f1`
- **Primary Hover:** `#4338ca`

## Typography
- System Sans font stack (`system-ui`, `-apple-system`, `BlinkMacSystemFont`, `'Segoe UI'`, Roboto, sans-serif).
- Tight, legible headlines (`tracking-tight`, natural weights, no artificial gradient text fills).
- Monospace font strictly reserved for keyboard keycaps (`[ ⌘V ]`, `[ Ctrl+V ]`) and technical resolutions.

## Core Principles
1. **Honest Product Truth:** Tell the user exactly what ScreenCraft does and does not do. No hyperbole, no technical jargon that confuses new visitors.
2. **True Theme Parity:** Flawless light mode and dark mode transitions across all elements, cards, and canvas backdrops.
3. **Flawless Mobile Ergonomics:** Zero horizontal overflow, touch-friendly tap targets, graceful wrapping on 360px–430px mobile screens.
4. **Preserve Identity:** The real ScreenCraft camera/frame logo (`/logo.png`) is the authentic face of the product.
